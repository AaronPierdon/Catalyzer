# CLAUDE.md — Nexus Development Principles

This repo IS the principles. Changing it changes the rules for every app.
- Follow PROMPTS.md → *Change the principles*: pick MAJOR / MINOR / PATCH, bump VERSION, add a CHANGELOG entry that
  says what an app must do. Never edit a rule without a changelog entry.
- Keep documents short and binding. Detail belongs in the Nexus UI kit (`Nexus/kit/docs`) or in the app's own docs.
- Aaron's latest word wins. When he states a new standing preference in any app's chat, it belongs here too.
- Commit messages end with the attribution lines the session asks for.
